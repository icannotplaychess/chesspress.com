## 04_OPENING_EXPLORER.md 

## Opening Explorer 

## Purpose 

The Opening Explorer allows users to study chess openings, understand their ideas, browse variations, and add lines directly to their personal repertoires. 

It should combine real-game statistics from the Lichess database with engine analysis from Stockfish. 

The explorer should be educational rather than simply displaying moves. 

## Features 

Users should be able to: 

- Search any opening by name or ECO code. 

- Browse opening trees interactively. 

- Click any move to continue exploring. 

- Move forwards and backwards through variations. 

- Instantly jump to any previous position. 

- Explore alternative continuations. 

## Position Information 

For every position display: 

- Opening name 

- Variation name 

- ECO code 

- Move number 

## Database Information 

Display: 

- Number of games 

- White win percentage 

- Draw percentage 

- Black win percentage 

- Most popular moves 

- Move popularity 

Data should come from the Lichess database. 

## Engine Information 

Display: 

- Current evaluation 

- Best move 

- Top engine continuations 

- Mate score when applicable 

Stockfish should provide all evaluations. 

## Educational Content 

Every important move should include: 

- Why the move is played 

- Strategic idea 

- Typical plans 

- Common mistakes 

- Possible transpositions 

The goal is understanding, not memorization. 

## Repertoire Integration 

Users should be able to: 

- Add a complete opening 

- Add a variation 

- Add a single line 

- Practice immediately 

- Bookmark positions 

## User Experience 

The Opening Explorer should feel fast, clean, and intuitive. 

Users should always know where they are in the opening tree and be able to transition seamlessly into practice or analysis.
