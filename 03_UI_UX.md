## 03_UI_UX.md 

## User Interface & User Experience 

## Design Philosophy 

ChessCoach should feel modern, premium, and distraction-free. 

The interface should encourage focused learning rather than overwhelm users with information. 

Every page should prioritize clarity, speed, and usability. 

The chessboard is always the primary focus. 

The design language should feel somewhere between a professional productivity application and a premium desktop program rather than a traditional gaming website. 

## Visual Identity 

## Theme 

Dark Mode Only 

The application uses a premium dark interface. 

## Primary Colors 

- Matte Black (Background) 

- Deep Charcoal (Secondary Panels) 

- Dark Navy Blue (Accent Color) 

The interface should avoid bright or saturated colors except when communicating important information. 

## Accent Usage 

Dark blue should be used for: 

- Selected navigation items 

- Active buttons 

- Primary actions 

- Links 

- Focus indicators 

Green, yellow, orange and red should only appear when representing evaluation or move quality. 

## Typography 

Use clean modern fonts. 

Recommended: 

- Inter 

- Geist 

- SF Pro Display (where available) 

Typography should have strong hierarchy. 

Large headings. 

Comfortable paragraph spacing. 

Readable chess notation. 

## General Layout 

The application should feel spacious. 

Avoid clutter. 

Large margins. 

Consistent spacing. 

Rounded corners. 

Subtle shadows. 

Soft animations. 

No excessive gradients.

## Mobile Experience 

Responsive layout.

Moves Coach 

Statistics

## Accessibility 

Support: Keyboard navigation High contrast Adjustable board size Adjustable text size Screen reader labels Color-blind friendly evaluation indicators 

## Empty States 

Every empty page should guide the user. 

Examples: 

“No repertoire yet.” 

Create your first repertoire. 

“No games analyzed.” 

Import a PGN or connect your Lichess account. 

“No reviews due.” 

Great job! You’re all caught up. 

## Error Handling 

Errors should explain: 

What happened. 

Why it happened. 

How to fix it. 

Never display technical messages to users. 

## Overall User Experience 

The interface should feel: 

Professional 

Calm Minimal 

Fast 

Educational 

Modern 

Premium 

Every screen should answer one question: 

## **“What is the next best thing for the user to learn?”** 

The application should always guide the user naturally toward improving their chess rather than simply presenting information.
